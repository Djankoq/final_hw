# Каркас краулера контактных данных

## Цель

Создать Spring Boot-приложение, которое в дальнейшем сможет обходить сайты организаций и извлекать открытые телефоны, email, адреса и ссылки. В текущей работе реализован каркас приложения и продемонстрирована работа с потоками.

## Архитектура

- `ContactCrawlerApplication` — точка входа и запуск демонстрационных задач.
- `ContactCrawlerService` — сервисный слой будущего краулера. В дальнейшем здесь можно организовать загрузку страниц, извлечение ссылок и контактов.
- `CounterWorker` — отдельная задача, созданная наследованием от `Thread`.
- `LoggerTask` — задача, реализующая интерфейс `Runnable` и передаваемая объекту `Thread`.

Предполагаемый дальнейший поток данных: стартовый URL → загрузчик HTML → извлечение ссылок → очередь непосещённых страниц → извлечение контактов → удаление дубликатов → сохранение результата.

## Этапы выполнения

1. Создан Maven-проект на Spring Boot 3 с Java 17.
2. Добавлен сервис `ContactCrawlerService` как основа бизнес-логики краулера.
3. Добавлен поток `CounterWorker`, созданный через наследование от `Thread`.
4. Добавлена задача `LoggerTask`, запущенная через `Runnable` в потоке `LoggerThread`.
5. Каждый поток пять раз выводит своё понятное имя и порядковый номер итерации.
6. Через `Thread.getAllStackTraces()` выводятся все активные потоки JVM, включая созданные потоки.
7. Метод `join()` обеспечивает корректное ожидание завершения обеих задач.

## Запуск

```shell
mvn spring-boot:run
```

Или запустить метод `main` класса `ContactCrawlerApplication`.

## Результат

В консоли отображаются сообщения `CounterWorker: 1...5`, `LoggerThread: 1...5`, список активных потоков и сообщение о завершении задач.
